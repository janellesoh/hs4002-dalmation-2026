# Archive: HCMST 2009 analysis (Presentation #1)

This folder holds the team's first analysis, built on **HCMST 2009, waves 1–3, version 3.04**
(Rosenfeld, Thomas & Falcon, 2015). It was used for Presentation #1.

The project has since moved to **HCMST 2017–2020–2022** (Rosenfeld, Thomas & Hausen, 2023),
the dataset named in our proposal. These files are kept for the record and are not part of the
current pipeline. The exact pre-switch state of the repo is also saved as the git tag `v1-hcmst2009`.

| Notebook | Author | Content |
| --- | --- | --- |
| `code/01_clean.ipynb` | Janelle | SES cleaning: income, education |
| `code/02_relationship_stability.ipynb` | Audris | Relationship stability outcome |
| `code/03_race_recode.ipynb` | Joyce (Shi Han) | Race recoding |
| `code/03_analysis.ipynb` | Yu Xin | Merging and income × race × stability chart |

Known issues found before the switch: the stability outcome covered unmarried couples only,
partner deaths were counted as breakups, and partner race omitted Hispanic origin.
